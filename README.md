# 색상 반전 (Color Inversion Toggle)

안드로이드에 기본 탑재된 **색상 반전** 기능을 버튼 하나로 켜고 끄는 초경량 유틸리티 앱입니다.
네이버·유튜브·카카오톡 등 앱 종류와 관계없이 시스템 화면 전체에 적용됩니다.

- 릴리스 APK 약 **47KB**, 외부 라이브러리 없음
- **인터넷 권한 없음**, 개인정보 수집·전송 없음
- Android 8.0(API 26) 이상, 라이트/다크 모드, 한국어

## 기능

| 기능 | 설명 |
|---|---|
| 큰 ON/OFF 버튼 | 메인 화면 가운데 버튼으로 즉시 전환 |
| 실시간 상태 동기화 | 시스템 설정·빠른 설정 등 **앱 밖에서 바꿔도** 화면이 즉시 맞춰짐 (앱 내부에 상태를 따로 저장하지 않고 항상 시스템 값을 읽음) |
| 빠른 설정 타일 | 알림창의 '색상 반전' 타일로 어디서든 전환. Android 13+는 앱에서 버튼으로 타일 추가 요청 |
| 홈 화면 바로가기 | 누르면 화면 없이 바로 전환되는 바로가기 추가 |
| 앱 아이콘 길게 누르기 | '색상 반전 켜기/끄기' 메뉴 |
| 최초 설정 안내 | 단계별 안내 + 진행 상황 체크 표시 + 명령어 복사 + 설정 화면 바로 열기 |

## 동작 원리와 기술적 제약 (중요)

안드로이드는 색상 반전 상태를 시스템 보안 설정 값
`Settings.Secure.accessibility_display_inversion_enabled` (0/1)에 저장하고,
값이 바뀌면 시스템이 즉시 화면에 반영합니다. 삼성 갤럭시(One UI)도 같은 값을 사용합니다.

- **상태 읽기**: 권한 없이 가능 → 앱은 언제나 실제 시스템 상태를 표시합니다.
- **상태 변경**: `WRITE_SECURE_SETTINGS` 권한이 필요합니다.
  이 권한은 시스템 보호 권한이라 **앱 안의 팝업으로는 받을 수 없고**, 최초 1회 ADB로만 부여할 수 있습니다.
  이는 이 앱만의 한계가 아니라 안드로이드 보안 정책이며, 같은 종류의 앱(예: 빠른 설정 타일 앱)도 동일한 방식을 사용합니다.
- 루트 권한은 필요 없습니다. 권한은 재부팅 후에도 유지되고, 앱을 삭제하면 사라집니다.

> 검토했지만 채택하지 않은 방법: 접근성 서비스로 설정 화면을 자동 조작하는 방식은 기기·언어·OS 버전마다 화면 구조가 달라 쉽게 깨지고,
> 과도한 접근성 권한(화면 내용 읽기)을 요구하며 Play 정책상 문제 소지가 있어 제외했습니다.

### 권한이 없을 때

앱은 정상 동작하며(상태 표시는 그대로), 버튼을 누르면 설정 안내로 이동합니다.
PC가 없는 사용자를 위해 **시스템 색상 반전 설정 화면을 바로 여는 버튼**을 제공합니다.
이 경우 전환은 시스템 화면에서 하고, 앱은 상태만 표시합니다. 이를 성공한 것처럼 표시하지 않습니다.

## 최초 설정 방법 (1회)

1. **개발자 옵션 켜기**: 설정 → 휴대전화 정보 → 소프트웨어 정보 → '빌드번호' 7번 연속 탭
2. **USB 디버깅 켜기**: 설정 → 개발자 옵션 → USB 디버깅 ON, PC에 USB 연결 후 휴대폰에서 '허용'
3. **PC에서 실행** ([Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) 필요):

```bash
adb shell pm grant com.cjsdudwls1.colorinversion android.permission.WRITE_SECURE_SETTINGS
```

4. 앱으로 돌아와 **'설정 완료 확인'** 을 누르면 안내가 사라집니다. 이후 USB 디버깅은 꺼도 됩니다.

**PC 없이 하는 방법 (Android 11 이상, 고급)**: 개발자 옵션의 '무선 디버깅'과
Shizuku·LADB 같은 온디바이스 ADB 앱을 사용하면 휴대폰만으로 위 명령을 실행할 수 있습니다(`adb shell` 부분을 빼고 `pm grant ...` 실행).
이 앱은 해당 앱들에 의존하지 않습니다.

## 빌드

요구사항: JDK 17+, Android SDK (platform 35, build-tools 35)

```bash
./gradlew assembleRelease
```

결과물: `app/build/outputs/apk/release/app-release.apk`

미리 빌드된 APK: [`release/ColorInversion-1.0.1.apk`](release/ColorInversion-1.0.1.apk)
(업로드 키로 서명돼 있습니다. 예전 1.0.0(debug 키 서명)이 설치돼 있으면 서명이 달라 업데이트가 안 되니 먼저 삭제하세요. 빌드 시 루트에 `keystore.properties`가 없으면 debug 키로 서명됩니다.)

## 설치

```bash
adb install -r release/ColorInversion-1.0.1.apk
```

## 예외 처리

| 상황 | 동작 |
|---|---|
| 권한 없음 / 권한이 도중에 취소됨 | 오류 없이 설정 안내 표시, 타일은 '설정 필요' 표시 후 앱 열기 |
| 이미 ON인데 ON 요청 (또는 OFF→OFF) | 아무것도 바꾸지 않고 "이미 켜져 있습니다" 안내 |
| 값을 썼지만 시스템에 반영되지 않음 | 다시 읽어 검증 후 실패 안내 + 시스템 설정 이용 안내 |
| 기기가 상태 읽기를 막음 | '확인 불가' 표시, 타일은 비활성(UNAVAILABLE) |
| 기기별로 설정 화면 경로가 다름 | 색상 반전 화면 → 접근성 화면 → 설정 순으로 시도 |

| 4 | 앱 밖에서 값 변경 (`settings put`) | 앱 화면이 즉시 '켜짐'으로 바뀌고 "시스템 설정에서 상태가 바뀌어…" 안내 |

| 6 | 빠른 설정 타일 추가 · 탭 2회 | `1 → 0 → 1`, 타일 활성/비활성 표시 일치 |
| 7 | 바로가기 실행 2회 | `1 → 0 → 1`, 화면 없이 전환, 앱 바로가기 등록 확인 |

| 9 | 다크 모드 | 다크 테마 정상 적용 |

> 참고: 스크린샷(screencap)에는 색상 반전이 적용되지 않은 화면이 찍힙니다. 반전은 디스플레이 출력 단계에서 적용되기 때문입니다.

### 실기기 체크리스트

1. 설치 직후 실행 → 설정 안내 표시, 1·2단계 체크 표시가 실제 상태와 일치하는지
2. ADB 권한 부여 → '설정 완료 확인' → 안내 사라짐
3. 버튼 ON/OFF → 화면 전체 색 반전 / 복구
4. 시스템 설정(접근성 → 시인성 향상 → 색상 반전)에서 변경 → 앱 상태 즉시 반영
5. 빠른 설정 타일 추가·전환, 앱에서 바꾼 상태가 타일에 반영되는지
6. 홈 화면 바로가기 / 아이콘 길게 누르기 메뉴로 전환
7. 앱 종료 후 재실행, 재부팅 후 상태·권한 유지
